# Loop journal — test-hygiene

> Per-loop append-only journal (loop-creator). One entry per fire, newest at bottom.
> Schema (going-forward entries):
>
>     ## fire N · YYYY-MM-DD · skill vX.Y.Z · <commit-sha>
>     meta: kind=prune|add · pkg=@muse/… · verdict=PASS|FAIL · firesSinceDrill=N
>     ratchet: testFiles before→after · netCoverage ± · fabrication 0
>     - What …  - Why …  - How-proven(mutation) …  - Risk …
>
> Theme: test-suite hygiene — removing low-value/duplicate tests (PRUNE) + adding missing
> high-value tests (ADD). Every test's value is proven MUTATION-FIRST (an ADD must FAIL when
> the target code is mutated; a PRUNE must cite another named test that catches the same
> behavior). Why per-loop (not a shared digest): concurrent loops collide and pollute a shared
> append file, so this uses a disjoint path. Worktree: /tmp/muse-test-hygiene (branch `loop/test-hygiene`).
> Convention: [README](README.md).
